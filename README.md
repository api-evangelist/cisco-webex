# Cisco Webex (cisco-webex)
Cisco Webex is a comprehensive collaboration platform that provides video conferencing, team messaging, file sharing, and calling capabilities for businesses and teams. The Webex developer platform offers REST APIs, SDKs, and integrations for extending and automating collaboration workflows across meetings, messaging, calling, devices, administration, and contact center scenarios.

## APIs

The Webex platform exposes the following REST APIs through the `https://webexapis.com/v1` base URL. Authentication uses OAuth 2.0 access tokens, personal access tokens, or service apps.

- **Webex Meetings API** - Schedule and manage meetings ([docs](https://developer.webex.com/docs/meetings), [OpenAPI](openapi/cisco-webex-meetings-openapi.yml))
- **Webex Messaging API** - Send messages and manage spaces ([docs](https://developer.webex.com/docs/messaging), [OpenAPI](openapi/cisco-webex-messaging-openapi.yml))
- **Webex People API** - Manage user profiles ([docs](https://developer.webex.com/docs/api/v1/people), [OpenAPI](openapi/cisco-webex-people-openapi.yml))
- **Webex Teams API** - Create and manage teams ([docs](https://developer.webex.com/docs/api/v1/teams), [OpenAPI](openapi/cisco-webex-teams-openapi.yml))
- **Webex Rooms API** - Manage spaces (rooms) ([docs](https://developer.webex.com/docs/api/v1/rooms), [OpenAPI](openapi/cisco-webex-rooms-openapi.yml))
- **Webex Webhooks API** - Subscribe to real-time events ([docs](https://developer.webex.com/docs/webhooks), [OpenAPI](openapi/cisco-webex-webhooks-openapi.yml))
- **Webex Devices API** - Manage room systems ([docs](https://developer.webex.com/docs/api/v1/devices), [OpenAPI](openapi/cisco-webex-devices-openapi.yml))
- **Webex Memberships API** - Manage room memberships ([docs](https://developer.webex.com/docs/api/v1/memberships), [OpenAPI](openapi/cisco-webex-memberships-openapi.yml))
- **Webex Team Memberships API** - Manage team memberships ([docs](https://developer.webex.com/docs/api/v1/team-memberships), [OpenAPI](openapi/cisco-webex-team-memberships-openapi.yml))
- **Webex Events API** - Compliance and audit events ([docs](https://developer.webex.com/docs/api/v1/events), [OpenAPI](openapi/cisco-webex-events-openapi.yml))
- **Webex Recordings API** - Manage meeting recordings ([docs](https://developer.webex.com/docs/api/v1/recordings), [OpenAPI](openapi/cisco-webex-recordings-openapi.yml))
- **Webex Call Controls API** - Telephony control ([docs](https://developer.webex.com/docs/api/v1/call-controls), [OpenAPI](openapi/cisco-webex-call-controls-openapi.yml))
- **Webex Attachment Actions API** - Adaptive card interactions ([docs](https://developer.webex.com/docs/api/v1/attachment-actions), [OpenAPI](openapi/cisco-webex-attachment-actions-openapi.yml))
- **Webex Organizations API** - Org administration ([docs](https://developer.webex.com/docs/api/v1/organizations), [OpenAPI](openapi/cisco-webex-organizations-openapi.yml))
- **Webex Licenses API** - License management ([docs](https://developer.webex.com/docs/api/v1/licenses), [OpenAPI](openapi/cisco-webex-licenses-openapi.yml))
- **Webex Roles API** - Permission roles ([docs](https://developer.webex.com/docs/api/v1/roles), [OpenAPI](openapi/cisco-webex-roles-openapi.yml))
- **Webex Workspaces API** - Workspace management ([docs](https://developer.webex.com/docs/api/v1/workspaces), [OpenAPI](openapi/cisco-webex-workspaces-openapi.yml))
- **Webex Admin Audit Events API** - Admin audit log ([docs](https://developer.webex.com/docs/api/v1/admin-audit-events), [OpenAPI](openapi/cisco-webex-admin-audit-events-openapi.yml))
- **Webex Converged Recordings API** - Unified recordings ([docs](https://developer.webex.com/docs/api/v1/converged-recordings), [OpenAPI](openapi/cisco-webex-converged-recordings-openapi.yml))
